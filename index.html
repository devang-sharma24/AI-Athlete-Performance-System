AI-Based Real-Time Athlete Performance Evaluation System Using Pose Estimation

This project presents an AI-powered system that automatically detects sit-up movements, evaluates athlete performance using age-based benchmarks, and generates intelligent performance grading with real-time analytics and dashboard visualization.

Problem Statement

Manual fitness evaluation is inconsistent, time-consuming, and subjective. There is a need for an automated, real-time AI-based performance evaluation system.

Literature Review

Pose estimation systems like MediaPipe and OpenCV enable real-time skeleton tracking. However, most existing solutions focus only on counting repetitions and lack structured performance evaluation models.

Research Gap / Innovation

Our system introduces: • Age-normalized AI scoring • Intelligent performance grading • Database-based analytics • Real-time automated evaluation

System Methodology

Dataset / Input

Real-time webcam feed processed using OpenCV and MediaPipe Pose landmarks.

Model / Architecture

Pose detection → Landmark extraction → Motion threshold logic → AI scoring → SQLite storage → Streamlit dashboard.
