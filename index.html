AI-Based Real-Time Athlete Performance Evaluation System

An intelligent computer vision system that automatically detects sit-up repetitions using MediaPipe Pose estimation and evaluates athlete performance through age-normalized AI scoring, grading classification, and statistical analytics.

Problem Statement

Traditional fitness assessment depends on manual supervision and counting, which can be inconsistent, subjective, and time-consuming. There is a need for an automated, real-time evaluation system that provides objective and data-driven athlete performance analysis.

Literature Review

Modern pose estimation frameworks such as MediaPipe and OpenCV enable real-time skeleton tracking. However, most existing systems focus only on repetition counting and lack structured AI-based performance evaluation with benchmarking and analytics.

Research Gap & Innovation

Our system introduces:
• Age-based performance benchmarking
• AI performance scoring model
• Fitness grade classification
• Real-time motion detection
• SQLite-based performance database
• Statistical analytics dashboard

System Methodology

Data Acquisition

• Live webcam video feed
• OpenCV frame processing
• MediaPipe Pose landmark detection

Rep Detection Logic

• Shoulder–Hip coordinate extraction
• Motion threshold comparison
• State transition logic (Up / Down)
• Automatic repetition counting

AI Evaluation Module

• Age-normalized benchmark calculation
• Percentage performance computation
• AI score generation (0–150 scale)
• Grade classification (Excellent / Good / Average / Needs Improvement)
• Result storage in SQLite database
