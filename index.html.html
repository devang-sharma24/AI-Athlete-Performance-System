AI-Based Real-Time Athlete Performance Evaluation System

This project presents an AI-powered system that automatically detects and evaluates athlete performance using real-time pose estimation and computer vision techniques.

Problem Statement

Traditional fitness evaluation relies on manual counting and supervision, which may be inaccurate and inconsistent. There is a need for an automated, real-time, objective system to evaluate athlete performance using AI.

Literature Review

Recent research in pose estimation (MediaPipe, OpenCV) demonstrates real-time human skeleton tracking. However, most existing solutions only count repetitions and do not provide structured AI-based performance evaluation.

Research Gap & Innovation

Existing systems lack intelligent benchmarking and analytics. Our system introduces:
• Age-normalized performance scoring
• AI-based evaluation grading
• Real-time motion detection
• Performance database & dashboard

System Methodology

Dataset / Input

• Real-time webcam video feed
• Human pose landmarks using MediaPipe
• Joint coordinate extraction

Model / Architecture

• OpenCV for video capture
• MediaPipe Pose for skeleton detection
• Motion threshold algorithm for sit-up counting
• AI-based scoring logic
• SQLite database storage
• Streamlit dashboard for visualization

Live Execution

The system processes live webcam frames, detects body motion, calculates repetition count, generates AI performance score, and stores the results for analysis.
